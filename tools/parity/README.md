# tools/parity: differential surface and behaviour harness (thaw-js vs Node)

Node is the oracle. `thaw-js-node` (a plain bin, no thaw-cli build) is the subject.
Each corpus runs on both; outputs are normalised and diffed per probe name.
Plan: `designs/plan-q9-systematic-parity.md` sections 0, 3 (H1), 6 (item 1-2).

## Layout

- `surface.js`: own names + descriptor shape (typeof, flags, length/name for functions, toStringTag) for globals, process and key builtin prototypes. Descriptors only, no getter is invoked.
- `corpus/*.js`: behaviour probes, `t(name, fn)` one line each. A throw is reported as `THROW <ErrorName>: <message>`, never a crash.
  - `invariants.js` strict-mode mutation violations and sloppy counterparts
  - `tags.js` `Object.prototype.toString` tags and `Symbol.toStringTag` values
  - `timers.js` Timeout/Immediate/Interval members, ref/unref/refresh, toPrimitive/dispose
  - `process.js` process member typeof and value shapes (no exit/kill/chdir/setuid)
  - `iterators.js` shared %IteratorPrototype% and Map/Set/Array/String iterator protos
  - `errors.js` captureStackTrace, prepareStackTrace, stack, cause, AggregateError
  - `names_lengths.js` name/length of builtins and global functions, function own props
  - `structured_clone.js` structuredClone per value family
- `seed/`: the original probes (sib.js, surf2.js), kept as reference only.
- `run.sh`: runs every corpus on node and on the runner, then `diff.py`.
- `diff.py`: normalise, diff, print a table, write gaps.json, gate against a baseline.
- `selftest.sh`: proves the gate on synthetic outputs (12 checks).
- `known-gaps.json`: recorded baseline. Gaps may only shrink.
- `skip.txt`: probe-name regexes dropped from both sides (bare-runner limits, not gaps).

## Run

    tools/parity/selftest.sh
    tools/parity/run.sh [OUT_DIR]               # gate: exit 1 only on gaps not in known-gaps.json
    tools/parity/run.sh --write-baseline [OUT]  # record current gaps (only after a fix lands)

Env: `THAW_JS_NODE` (runner; default `/home/fedora/work/thaw-tmp/ra8/target/release/thaw-js-node`), `NODE` (oracle, default `node`), `PARITY_TIMEOUT` (seconds per thaw corpus, default 60). Default OUT is `/home/fedora/work/thaw-tmp/parity-scratch/out`. Nothing is written into the repo except `known-gaps.json` on `--write-baseline`.

## Output and exit codes

- Table per corpus: probes compared, MISSING, DIFFERENT, EXTRA (thaw-only, informational).
- Per gap: status (`known` / `NEW`), kind, probe id `corpus::name`, node value, thaw value.
- `gaps.json` in OUT: all gaps with both values.
- Exit 0: no new gaps. Exit 1: at least one gap not in the baseline (listed). Exit 2: harness error (oracle failed, duplicate probe name in one file).
- Fixed gaps are listed as "fixed since baseline"; they pass, and `--write-baseline` ratchets them out.

## Normalisation (diff.py)

- `THROW <Name>: <message>` compares by error name only. Messages differ by engine.
- Absolute `/home/...` paths, `0x` addresses and `<n>ms` durations are masked.
- Whitespace is collapsed. Lines without ` = ` are raw probes keyed by the whole line.

## Adding a probe

Keep expected output generated by node, never hand-written. Probe names must be unique per file (a duplicate is exit 2). Use `G('Path.To.Global')` instead of bare identifiers so a missing global is a visible gap, not a ReferenceError. Probes that need `require` or `Intl` go in the skip list, not the baseline.

## Known limits

- The prebuilt `ra8` runner predates #556-#562 (it has #554/#555). Gaps the later PRs closed still show as gaps here. Re-run against a current runner build before reading the baseline as current.
- The runner has no `Intl` and no `require`; probes that touch them are skipped (`skip.txt`).
- Node-only globals such as `fetch`, `WebSocket`, `Blob` are counted as gaps when thaw lacks them; the plan's H2 routed run is the check that decides whether they are runner-only.
- The surface corpus reports `globalThis.<name>` and `<name>` separately for each global, so one missing global can appear as two gaps.
