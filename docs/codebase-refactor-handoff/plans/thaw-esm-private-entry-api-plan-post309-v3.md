# Private native ESM entry API correction (v3)

This supplements the immutable post307 v1/v2 plans after independent HOLD. Source-only at HEAD310; no product execution or managed edit.

The owner stores source/import records, a monotonic sequence, the selected-entry ready Promises, and the captured intrinsic `Promise.prototype.then` in `Ctx::store_userdata`. It stores no typed `Module`: pinned `Module<Declared>` and `Module<Evaluated>` have distinct markers and the engine's loaded-module cache owns the module. After `Module::eval`, obtain its namespace object without reading bindings; capture that `Object` in the fulfillment callback. If `namespace()` fails, reject the already-published bridge Promise. The callback handles resolve failure by rejecting the same bridge with the original caught value, and every declaration/eval/callback/attachment failure rejects it. The captured intrinsic `then` is invoked with `This(eval_promise)`, so user replacement of `Promise.prototype.then` cannot silently skip callback attachment.

Registration accepts one finite JSON graph with unique keys and all targets present, rejecting embedded NUL in keys before minting. It returns a **Function** bound to the newly minted private entry name, never that name/string token. The generated IIFE calls the returned function and retains it only in its lexical scope. There is no global `eval(token)` endpoint; same-realm user code cannot guess an older entry name to ask for its namespace. A user-created new graph can only evaluate its own returned function. The owner checks that bound entry is registered; nested resolution is restricted to that entry's own collected imports. A nonbundle absolute import is always rejected.

Create and store the ready Promise before `Module::declare`/`eval`, with no userdata guard across engine calls. Reentry through the same bound Function returns the same ready Promise and does not evaluate twice. Existing `load_impl` drives jobs; no nested draining. An unrun test must inspect the absence of public registry and token-eval API, old-name absolute import rejection, repeated bound evaluation identity, a synchronous self-reentry hook, and tampered `Promise.prototype.then` before a second graph load. The pure native route still intentionally publishes its selected namespace through `module.exports`; mixed CJS facade, Worker route, and whole Task12 remain open.
