# Private native ESM registration and entry API plan (source only)

Base HEAD307 `c2482ced9611e3baabb0a827adcad4c049b0cd3a`; no product execution or managed edits. This is the pure native-route precursor, not mixed facade/Worker completion.

Store `NativeBundleOwner<'js>` in `Ctx::store_userdata`, with `Cell<u64>` for sequence minting, a `RefCell<HashMap<String, SourceRecord>>` (source plus canonical import map, owner sequence), a `RefCell<HashMap<String, Module<'js, Declared>>>` for entries/dependencies, and a `RefCell<HashMap<String, Promise<'js>>>` for an entry's mapped completion. Implement one `JsLifetime` for the owner using same-layout lifetime change. `Opaque::clear` drops these modules/promises before `JS_FreeRuntime`. Every lookup copies owned record or clones Module/Promise, then drops both userdata guard and RefCell borrow before declaring/evaluating, invoking JS or reading namespace. Loader `load` declares the requested source and records a clone before returning it. No `Persistent`, separate TLS, or global registry object.

Expose a readonly/nonconfigurable `__thaw_register_native_bundle(payload_json)` created during `ensure_context`, before platform/user scripts. The renderer supplies one JSON string containing `main` and a finite array of `{key,source,imports}` from its collected modules; Rust parses/validates unique keys, existing main and same-payload import targets before minting a checked monotonic sequence. Rust prefixes **all** records itself and returns the opaque entry token; caller never chooses a prefix or cross-owner target. A malformed or duplicate payload fails without replacing earlier records. This public host call can register a *new* self-contained bundle, but cannot map its imports into an older sequence or change an older record. No returned API yields an old raw namespace.

Expose readonly/nonconfigurable `__thaw_eval_native_entry(token)` returning `Promise<'js>` for the selected public value. For a new token, clone its entry SourceRecord, release guards, call `Module::declare(ctx, unique_name, source)`, record a clone, then call `Module::eval` with no RefCell guard held. `Module::eval` yields `(Module<Evaluated>, Promise)`; save its evaluated Module and a completion Promise before returning. Use `Promise::then()?.call((This(eval_promise.clone()), success_function))` where the success function obtains `evaluated.namespace()` and returns it; rejection propagates the original thrown value. `rquickjs` uses `This(promise)` itself for this exact call (`value/promise.rs:205–215`). Store the **mapped** Promise and return it on repeated entry requests so entry code evaluates once. Source proof: `Module::declare` uses compile-only mode (`module.rs:259–279`); QuickJS `js_new_module_def` adds it to `ctx->loaded_modules` (`quickjs.c:29634–29656`); `Module::eval` yields evaluated handle + promise (`module.rs:375–396`). Loader `load` is invoked for nested dependencies while eval links; it reads the same private owner. Any reentrant registration/evaluation when status is in-progress needs a source-tested state machine before claiming sync require or mixed cycles.

Resolver behavior: read private owner, clone record, release guard; if `base` is a registered `thaw-bundle:` source, resolve **only** `record.imports[name]` to a target in the same minted sequence and private registry. If `base` is nonbundle, reject every `thaw-bundle:` request (and any other request); no surrounding eval absolute-entry exception. The host entry function itself bypasses resolver for the initial module. The loader reads source only from private userdata. The renderer changes `globalThis.__thaw_module_ready = import(prefix + main)` to `__thaw_eval_native_entry(__thaw_register_native_bundle(payload)).then(...)`; pure route's `module.exports` remains the native namespace after readiness. The bridge global `__thaw_bundle_exports[main]` publication remains as today. There is no public source registry or namespace lookup.

Unrun controls: pure cycle/TDZ, query suffix identity, same-key revised source, mixed legacy fallback, declared-context gate; nonbundle eval `import(known_absolute)` rejects while host entry succeeds; finite literal dynamic import of a prior owner rejects from inside a new module; repeated host entry request returns same Promise/module effects once; ordinary same-realm user script cannot mutate the private table or reset sequence; returned pure namespace remains deliberate baseline. Test a fresh TLS context where the first minted sequence is known, rather than adding a debug exposure. Keep legacy mixed/Worker routes unchanged and the broader Task 12 finding open.
