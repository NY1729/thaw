## Exact existing machine convention

SysV x86_64 Unix: public function RDI points to f64 arguments; values use XMM0..7, depth maximum8. At function entry RSP%16=8. machine.rs227 emit_spill subtracts0x48=72, stores live XMM at RSP+register*8, saved RDI+64; helper-call stack is16 aligned. emit_restore238 reverses exactly. unary247/binary258/reversed270/ternary289/quaternary302 helpers move consumed operands into XMM0..N, call absolute address via RAX, move XMM0 result back to destination, then restore only registers below destination. emit_move122 is physical XMM copy and is also used for ABI shuffles: cannot automatically attach semantic metadata to every call of emit_move.

emit_recursive_call127 allocates136: arguments0..56, saved prefix registers64..120, RDI128; sets RDI=RSP and relCALL to code offset0. Result XMM0 moves to base then restores prefix. Its relative displacement is calculated from whole code vector's next offset, so adding prologue at offset0 requires no target change beyond preserving existing computation.

## Smallest permanent metadata frame

Reserve16 bytes at machine_code entry (before opcode emissions). Bytes0..7 parallel XMM slot presence:0 present,1 undefined,2 null; bytes8..15 scratch if needed. Subtracting16 preserves entry alignment and existing72/136 temporary frame alignment. Initialize metadata slots safely; only initialized/live slots read. This needs no new callee-saved register, no RBX/R12/RBP convention changes, and no public ABI change. Ordinary frame metadata addresses [RSP+slot]; while emit_spill active [RSP+72+slot]; while recursive136 frame active [RSP+136+slot]. Centralize offset/extent constants; never use temporary spill slots0..63 as persistent metadata. Do not add a push without recalculating helper alignment.

Add dedicated machine.rs emitters: set_slot_presence(slot,state), copy_slot_presence(dst,src), read_slot_presence/conditional branch, scoped helper presence reset/snapshot, terminal publish and epilogue. Copy through integer scratch RAX/RDX only at semantic boundaries where those registers have no live meaning. Preserve machine error branch RAX until its test; do not insert metadata copies between emit_restore and has_call_error test that overwrite RAX. Keep emit_move as physical-only; introduce semantic value move/copy explicitly at stack transformation sites.

All RET paths need balanced +16: normal codegen2720; EarlyReturn2087–2093; uncaught typed throw2014; machine.rs48 emit_return_if_call_error inline xor/RET; any new/other emission ending0xc3 found by whole compiler search. Return helper publication itself must preserve selected XMM0 and RDI through spill/restore and leave frame before RET. ## Helper state calls without clobbering live values

Presence runtime helpers should return u64 (RAX) or accept integer state in RDI per C ABI; existing f64 take_present consumes shared flag and returns XMM0, insufficient for selected-slot metadata. Before calling state-reset or materializer, spill full live depth so consumed XMM operands and RDI survive; after restore RAX return remains usable (restore has no RAX writes). To capture helper publication after ordinary value helper, spill all live result/prefix registers, call read/reset publication, restore then store AL to result metadata. Calling presence helper naked can clobber XMM result even if its return is integer. For full depth8, never allocate a ninth XMM scratch register; integer state operations suffice.

Reset publication immediately before only presence-producing helper invocation, with full operands preserved; snapshot immediately afterward before another helper. Audit helper-to-helper publication behavior. Ordinary arithmetic/normalization result set present explicitly. Existing emit_unary/binary/... can accept an output publication policy, but their inner ABI move/spill logic must stay physical-only. Inline nullish materializers can load NaN/+0 bits via integer scratch into target XMM before arithmetic and mark present; if materializer calls Rust, same full live spill discipline. Boolean/string/Dynamic materialization requires attested kind, not raw pointer guess.

## Recursion/argument bridge

Per-frame slots solve result presence but raw optional inputs need a scoped internal argument-presence source. Public f64 ABI stays unchanged: existing Rust call wrapper can set a TLS input-metadata pointer/count valid for call duration, prologue copies metadata via a helper with arguments/registers preserved, and wrapper restores prior pointer. Raw external invocation defaults arguments present unless its existing typed host contract supplies absence. Recur must temporarily publish metadata for its packed argument array, invoke offset0 entry, snapshot returned publication, then restore previous input pointer/publication; stack-local array lifetime ends after return. A separate internal entry convention is also possible, but cannot read bytes after public caller's f64 array without an attested allocation length. Never silently read arguments+8 as metadata.

Rust callback record {word,presence} and machine.rs outer save/restore (existing609–619) consume terminal publication. Do not clear Dynamic epoch per callback: outer DYNAMIC_VALUES scope owns wrappers; recursive/nested callback scopes restore outer entries only after preserving returned wrapper ownership. This is the ABI/read dependency for emitter work, not an instruction to introduce a second registry.
