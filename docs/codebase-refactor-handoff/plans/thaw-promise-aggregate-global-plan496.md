## Actual storage contracts

Compiler collections.rs compile_array_lit400 and compile_object_lit854 evaluate element/field expressions, allocate arena storage, then raw-store compiled values. Tuples share array/tuple handles and sized element storage (collections.rs10,147; expressions.rs385). Expressions ArrayIndexAssign path uses thaw_array_ensure_index and raw-stores into returned interior buffer slot; PropAssign resolves object field pointer and raw-stores. These raw stores do not acquire native Promise Box ownership. Conservative arena scanning supplies reachability edges but does not create a Box token; borrowed Promise aliases therefore need internal ownership before an external owner disappears.

declare_globals hir_codegen.rs585 initializes module storage zero; module initializers at675/814 raw-store evaluated values. Global Assign currently falls through ordinary variable store unless explicitly routed. A native Promise global is genuine external storage, not an arena-owned slot; stack function cleanup must not release it.

Runtime native_values/arrays.rs has physical buffer relocation/copy/mutation operations: ensure_index553, resize605, fill787, slice841, concat918, to_reversed961, push_values981, unshift_values1063, pop1189 and subsequent mutation routines. Array handle points at a backing buffer; slot ownership keys must follow physical buffer slots, not handle addresses. Existing Promise helper requires owner and slot in the SAME allocation. Object fixed-field slots can use object allocation as owner; tuple/array slots use backing buffer allocation.

Dictionary in LLVM functions.rs94 follows Json/Dictionary representation, not a native object field-pointer buffer. Do not route it by treating its Json pointer as Promise slot owner. Dictionary Promise values require the existing native projection/Json live-bridge contract to retain identity and lifetime; exact value producer/callee routing remains an explicit dependency. No raw Promise pointer may be injected as arbitrary Json payload.

## Minimal staged implementation

1. Fixed arena object/tuple/array construction and assignment: use existing checked internal slot helper for exact Promise fields. Initialize physical slot null before first acquire. Per selected RHS acquire internal before pointer publication; transfer/release owned temporary on both success/error according to established expression normalization. Reads are borrowed and acquire only when escaping to return/await/external owner. Keep object accessor invocation semantics: accessor setters consume their own ABI, not a fabricated backing-field store.

2. Active union/optional payload fields: owner table key is the actual pointer-sized payload location. Inspect old active tag to release the old Promise token and new active tag to acquire the new one. Inactive payload must not be decoded. Update tag+payload coherently after acquire, preserving original type/identity. Exact standalone Promise helper cannot raw-read a non-Promise old union word; add a narrowly typed aggregate-slot wrapper or pass normalized old/new Promise pointer values into existing bookkeeping, keeping one internal token per physical Promise-bearing slot. Nested inline aggregate storage needs recursive typed field traversal, not all-pointer assumptions.

3. Array storage moves/copies: retain internal tokens for every destination Promise slot BEFORE publishing destination buffer/handle. Copies create independent slot tokens; relocation transfers bookkeeping or acquires destination then releases old. After raw memcopy, do not call helper on an untracked non-null destination: null-initialize then checked-store each tracked Promise field, or provide a narrow migration API validated against existing slot records. Shrink/delete/pop releases removed slot tokens promptly; old buffers remaining arena allocations must not keep stale references/records indefinitely. Fill and overlapping splice/copyWithin acquire RHS/temporary owners before any overwritten token release. Preserve duplicate aliases as separate edges/tokens. Runtime width alone cannot discover Promise fields: compiler must supply typed Promise-field offsets/active union descriptor through these existing mutation ABIs. Reuse compiler native layout descriptors; no new universal value registry.

4. Globals: one external token per active Promise global field. Initial write/overwrite normalizes selected RHS to owned, saves old active owner, publishes new global storage before old release. Register module global cleanup at the real module/runtime teardown boundary, not ordinary arena reset: globals survive it. Arena globals holding aggregate pointers root their aggregate and internal child graph; exact Promise global external root follows existing external Box count. Declare/init and Assign must share this helper. Throw/module-initializer failure releases already initialized external globals according to module lifetime; no per-function cleanup may consume them.

5. Dictionary/native bridge: locate actual insertion/deletion/clone/project callees before changing their ABI. Retain descriptor's native owner by its exact type. Promise-specific descriptor already uses internal_references with reset release; a dictionary-held descriptor must be traced from its actual live Json/native projection owner graph. Preserve object identity, type/layout guard and native Promise reason graph; do not assimilate thenables or copy arbitrary raw Box pointer into Json. Full Json/JsValue provenance/lifetime gates remain open until this bridge is proved.

## Native reason descriptor interaction

Existing tag29 descriptor owns an internal Promise token and is reclaimed through the descriptor reset map; its arena pointer fields/REFERENCES trace original owner. Array/object/tuple descriptor retains arena aggregate reachability but aggregate Promise children still require their own physical slot tokens. Promise→descriptor→aggregate→Promise cycles must consist of internal tokens and graph edges, with external root only for real outside handles. Do not add external retain to every field/capture: that self-pins cycles. Duplicate descriptor/slot aliases each release their own internal token exactly once after record removal outside map borrows.
