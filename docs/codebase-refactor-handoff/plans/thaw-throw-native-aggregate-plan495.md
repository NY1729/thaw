## Reusable transport and its actual limits

HIR inference/coercions.rs50 retain_full_native_object_projection and fixed_object_supports_live_projection prove a fixed Object's live projection only. Do not apply this object projection to an Array/Bytes/Map/Set/Tuple/closure/Promise/Symbol pointer. LLVM json_bridge/encoding.rs173/246 object,947/955 array,1156/1164 tuple encoders produce Json conversion graphs; they do not by themselves establish identity equality with the original native owner. Ordinary serialization is unsuitable as throw provenance: it can snapshot, invoke accessors or reject opaque values.

Native callable bridge exists: dynamic_host/callbacks.rs compile_register_native_callback_from_closure[_with_rest/_with_mode], backend adapter registration and retained JsValue result. json_bridge/encoding.rs609/633 and1353 invoke it with exact closure signature. This can preserve callable behavior in host space, but a fresh bridge per throw is not original function identity; reuse/cache identity through existing projection ownership if host conversion is needed. Registering a closure must retain its captures and handle lifetime. Do not register a generator producer as an ordinary JS callback (HIR coercions.rs551 onward distinguishes its resume ABI).

Native Promise callback finisher (callbacks.rs1403 onward) adapts an async callback result to a host Promise by polling/finishing it. This is not a generic thrown-Promise transport: throwing/rejecting a Promise keeps the Promise itself as reason and must not await, finish, adopt or assimilate it. runtime/promises.rs stores a rejected reason tuple and has existing arena roots/frame ownership; reuse that ownership machinery for a native reason carrier. Its tag/payload must retain kind/layout. Promise.resolve adoption must remain separate from Promise.reject reason storage.

No universal identity-preserving native Symbol/Bytes/Map/Set/Weak*/Tuple/Array-to-host bridge was established by these source reads. This is an explicit dependency, not permission to manufacture a handle or fall back to object tag0. Symbols require symbol identity, closures function identity, promises Promise identity; all must survive escape independently of diagnostics.

## Minimal coherent implementation route

Preserve native representation inside the compiler/runtime exception reason tuple instead of forcing every aggregate through JSON or QuickJS. Add a compact native reason descriptor beside existing owner/payload: actual category plus compiler-known layout/signature/type identifier needed for safe extraction. This is exception metadata, not a global value registry. Existing raw owner remains identity. Descriptor must discriminate object, array(element/state representation), bytes, map/set/weak variants, tuple layout, symbol, closure signature/captures, Promise. Public typeof category is symbol/function/object; layout identity is stricter than typeof.

HIR publication takes evaluated value exactly once plus its actual descriptor. Separate generated native-reason setter from __thaw_set_pending_exception_object; keep that setter Object-only. Active union branches select full descriptor. Publish reason ownership before diagnostics, clear stale fields coherently, and branch on acquisition failures immediately. Formatting uses fixed diagnostic descriptions for opaque values, never user valueOf/toString/getters. Preserve original expression clones/borrow use as prior prerequisite requires.

LLVM publication/catch extraction consumes descriptor and never maps an arbitrary native reason to Object. The lexical catch carrier must retain the reason, descriptor and current-value validity as one mutable unit. typeof reads actual category; strict identity compares actual owner and category; asserted native extraction validates exact compatible type/layout before unpacking. Reassignment invalidates the original tuple and updates current carrier; closures capture the shared carrier cell, not detached old payload. A compiler-internal native-reason carrier arm can preserve all supported opaque layouts without teaching each catch union to pretend they are Object. It needs explicit inference/closure traversal/ABI support; no unsafe coercion to public object layout.

Carry the same tuple through synchronous catch, rethrow, Promise.reject, native Promise reaction frames, async await rejection, escaped catch closure and callback exception marshaling. Extend existing roots, not a second ad hoc registry: arena-backed owner plus transitive closure/object children must stay rooted; native Promise Box ownership needs its existing retain discipline rather than treating it as an arena allocation. Native Symbol allocation/ownership must be verified in its constructor/destructor before retention. Record whether payload is borrowed or owned, and release exactly once after carrier/frame lifetime ends, including failed publication and replaced values.

When a native reason crosses into QuickJS, use an existing proven live bridge only for its supported kind. Callable bridge can be reused with stable identity and owned handle; fixed object live projection can be reused under its existing compatibility proof. Capture the resulting actual retained JsValue into exact graph using the existing borrowed-handle grant/root/lease path, not numeric placeholder. For unsupported aggregate bridges implement kind-specific adapters preserving native owner identity and lifecycle before claiming host route complete. Do not run the Promise finisher or thenable assimilation to represent a rejected Promise. Pure-native preservation should not depend on loading QuickJS.
