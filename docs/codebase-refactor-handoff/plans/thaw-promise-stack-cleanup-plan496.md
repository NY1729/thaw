## Minimal representation and invariants

Track only synchronous physical Promise stack slots in a compiler table: pointer slot, runtime i1 owned-flag slot, lexical cleanup scope identity. This is compiler codegen bookkeeping, not a runtime generic value registry. Runtime flags are necessary: conditional assignments and loop iterations cannot be represented by mutating a compile-time bool. Allocate flag in dominating function entry and initialize false there. Initialize fresh local pointer null before first possible cleanup. Borrowed synchronous parameters get false with their actual incoming pointer, no entry retain. Arena/frame/global slots remain outside this stack owner table and retain their distinct contracts.

After a synchronous local write, normalize the selected RHS to one external owned token (owned factory transfers; borrowed alias checked-retains). Acquire before publishing and before releasing old token. Load old pointer/flag; store new pointer and true flag; destroy old only if flag was true. Borrowed parameter first assignment therefore never destroys caller's incoming owner, but its replacement is subsequently owned. Self-assignment acquires before release and is safe. Runtime retain failure must leave old pointer/flag unchanged and clean RHS-owned temporaries on any intervening failure. Use existing conditional splitting so only selected arm is evaluated and ownership classified.

## Scope and exception exits

Add a small compiler stack of Promise cleanup scope IDs alongside existing block/loop/catch codegen. Each ownership record belongs to the actual binding lifetime, not whichever block last assigned it. Associate catch target with the scope boundary that remains live there. Throw/check-error to a local catch cleans only scopes it unwinds: outer slots still live in handler must survive, including outer borrowed parameter whose assignment made its flagtrue. Function-escaping error cleans all stack owned flags. Clear each flag before destroy to make repeated cleanup edges safe.

Named paths: compile_block/statements.rs123, compile_if branch snapshots, compile_while and loop break/continue targets, compile_try statements.rs728+ catch_stack push, compile_throw_builtin_error expressions.rs36+, generic pending-error transfer hir_codegen.rs1286+, explicit Throw lowering, Return and fallthrough return. Centralize cleanup emission at the shared exception transfer helper where possible; catch target metadata supplies boundary. Loop break/continue clean loop-body locals exited, not enclosing loop/function bindings. Normal block exit cleans only bindings actually leaving scope. Snapshot/restore ownership record maps while generating alternatives; runtime flags remain the state source, so a handler or merge does not infer ownership from one compiled branch.

Preheader promotion scope currently saves catch_stack but also needs the associated cleanup boundary snapshot: a failure before loop cannot unwind scopes created later in body. Do not reuse active nested body cleanup stack while temporarily emitting at preheader. This is the same dominance/runtime-context issue as the saved catch stack.

For thrown Promise, first publish the internally owned native reason descriptor/carrier before releasing stack external tokens, so cleanup cannot destroy the thrown value. For returned Promise-bearing union, normalize the active member to external ownership and protect it before cleaning locals. Opaque union return ABI remains the prior plan's required dependency; no claiming full cleanup by covering exact Promise only.
