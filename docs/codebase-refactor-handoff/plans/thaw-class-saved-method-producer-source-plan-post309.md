## Minimal coherent native-instance producer

Use the existing raw Function/CallableFunction pointer ABI. At `lower_native_method_reference`, retain the own-field/static exits. For an instance signature, lower and bind the source receiver once. Build a typed `HirExpr::Conditional` whose true arm is the existing `MethodRef` or captured closure and whose false arm is `OptionalValue(OptionalNone(function_type), function_type)` (the existing typed-zero-pointer lowering). Query `__thaw_object_has_class_identity(bound_source, declaring_class)` only after the receiver binding. Both arms have the same Function result type, so explicit Function locals, assignments, captures, parameters, returns and arrays can transport the absence without changing ABI. The false arm must never allocate a closure or call the method symbol. The raw zero denotes **undefined**, not null; unit308's recursive status/typeof/equality paths recognize that distinction.

This producer cannot be merged safely in isolation. Before enabling it, the dependent source/LLVM routes need one coordinated reviewable candidate or ordered precursor units:

1. In HIR, route direct/saved `.call/.apply/.bind` through the actual selected Function value and move the absent-property check before evaluating `thisArg` and forwarded expressions. For plain `f(args)`, preserve argument-before-noncallable-TypeError order; for `f?.(args)`, skip arguments. Keep valid `uses_this` MethodRef receiver validation at invocation and valid no-this closure behavior with arbitrary `thisArg`. Avoid source-symbol metadata rewriting an absent alias.
2. Guard Function→JsValue/Json coercions in `inference/coercions.rs:170,440–475` before `registerNativeCallback`. LLVM `dynamic_host/callbacks.rs:1186–1445` and `json_bridge/encoding.rs:~600–640,~1338–1355` currently register Function fields/elements directly; map zero to the established undefined channel or JSON object omission/array null as appropriate. Console's Function branch at `console.rs:~141–145` currently prints `[Function]` unconditionally. Check N-API, Promise handler/replacer and dynamic-host callback callers against the same raw-null contract. Units 298/300/303/308 are precursors, not proof these remaining families are safe.
3. Only after those consumers are guarded, add the instance producer and unrun regressions. Ensure method identity for the same real class source/alias stays stable under pointer transport; ordinary vs graph QuickJS callback adapters can differ as JS wrappers but unit308's private provenance handles cross-mode equality. Preserve actual own-function field precedence and static method behavior.

Suggested unrun controls: forged physical marker/source read yields undefined; `typeof`, `=== undefined`, `!== null`, `== null`, logical fallback and nested Union/Optional retain distinction; saved value through annotated variable, reassignment, parameter/return/capture and array; `f(effect())` evaluates once then throws, `f?.(effect())` skips; `f.call/.apply/.bind` and immediate `fake.method.call` fail before `thisArg`/spread effects; real `uses_this` call with forged `thisArg` evaluates arguments then fails, while no-this captured method ignores arbitrary `thisArg`; real own-function shadow and inherited valid method; Function→Json/JsValue, object/array serialization, console and host callback do not register/dereference zero. Separately gate `C.prototype.method` delete/replace and `Object.getPrototypeOf` token behavior; no narrow producer can claim those full semantics.
