# Mixed ESM/CJS live facade: source plan after private entry unit312

Managed HEAD `c4599869952cab2d72d5786142a5ed99bddfd94d`; read-only design. Existing private entry is deliberately pure-ESM only (`bundle/collection.rs:608–621`) and has a bound evaluator but no public name-based entry method (`quickjs/context.rs:209–332`). No product execution or managed edit.

## Smallest coherent route

1. **Keep one origin resolver.** Extend the *existing* `STAR_ORIGIN_RUNTIME` in `bundle/render.rs:22–205`: its explicit-before-star, ambiguity, diamond and edge-version rules stay intact. Change only `read` for an `esm` terminal from `__thaw_bundle_require` (`render.rs:115`) to a private native namespace read. Retain the current `cjs`/`cjs-default` `edges[sourceKey][spec]` and `value[name]` path, which performs a fresh getter read, not a captured value. `namesOf` must still wait for the opaque edge before publishing star names; the existing `track` retry handles reentrant ownKeys. Do not synthesize an ESM `export const` snapshot for a CJS getter.

2. **Make native terminal reads possible without public import.** Extend `NativeBundleOwner` (context.rs:193–205) with a per-registration map of *declared module handles*, keyed by its Rust-minted `thaw-bundle:<sequence>:<key>` names. `BundleModuleLoader::load` and entry declaration record cloned `rquickjs::Module<Declared>` handles after source lookup; pinned `Module` is `Clone + JsLifetime` (`rquickjs-core 0.12.2 value/module.rs:198–210; js_lifetime.rs:184`). Retain these in context userdata, which `Opaque::clear` drops before runtime free. The private read method fetches/clones the handle and releases userdata/RefCell guards **before** calling `Module::namespace()`/`Object::get(name)`; call it only after the module graph has linked, so QuickJS's own var/function/lexical cell timing and TDZ are observed. An absent key or failed namespace read must propagate the original JS exception, not fall through to CJS. This is a bounded extension of unit312's owner, not a second module cache or a public `import(absolute-name)` escape.

3. **Keep opaque execution in the bundle wrapper.** The existing `__thaw_bundle_require` cache, import/require maps, edge publication and rollback (`render.rs:344–369`) remain the only CJS executor. Capture a per-bundle opaque loader in the registration capability, never a realm-global latest-bundle require; it must call the same require and publish the same origin edge. Register an opaque dependency shell for native linking only after the per-bundle loader can run at the shell's evaluation point, in static import order. Its source must not expose named CJS exports to native linking. A shell whose body merely `export {}` without executing the CJS dependency would reorder side effects and is not acceptable. This adapter is a source gate before enabling the mixed route; if the host API cannot inject the per-bundle closure without a public global lookup, freeze the private-read precursor alone and leave `native_esm=false` for mixed graphs.

4. **Reuse the scope-aware import visitor.** `module_transform.rs:615–955` already knows imported aliases, lexical shadowing, shorthand, detached named calls, optional calls and tags. For targets that can end in opaque origins, rewrite each named/default use to the existing origin `resolve/read` against the correct canonical owner; preserve the side-effect import and its position. Keep pure-native imports unchanged. Namespace and `export * as ns` values use one per-owner facade; finite dynamic `import()` uses the same facade after readiness. Preserve separate import vs require target maps and origin graph (`collection.rs`/`render.rs`). Do not use textual substitution or remove a static import before its side effects are accounted for. Nonliteral dynamic imports still force legacy, as the collector currently records `has_nonliteral_module_load`.

5. **Facade is a bundled-consumer object.** Build it in the existing renderer around `origin.names/resolve/read`, cached by canonical owner key. A fresh extensible Proxy target can report late opaque keys in `ownKeys`, `get`, `has`, and configurable enumerable descriptors without violating the non-extensible native namespace target invariant. Prevent `preventExtensions`/`seal`/`freeze` from succeeding while its key set can grow; test the proxy invariant explicitly. The mixed entry's `module.exports` and bridge-ready value must be this facade rather than unit312's raw native namespace. Pure native still returns its real namespace. A direct public import of a minted absolute module name remains disallowed by unit312's private bound entry; native module names are never exposed as a user entry API.

## Review gates and remaining scope

- **First reviewable code slice:** private declared-handle read + origin `esm` terminal switch, with mixed route still disabled, proves no eager CJS require on ESM cycles. Then a coherent mixed adapter/visitor/facade slice may enable eligible mixed graphs. This partition avoids accepting a broken linker as a partial fix.
- **Synchronous CJS-first require:** current require (`render.rs:344–369`) cannot synchronously evaluate a native module and inspect its immediate Promise. It must reuse the same declared module, reject TLA before evaluation, preserve rollback and not pump jobs. Until then, mixed graphs with a CJS→ESM require edge cannot use the native route.
- **Workers:** current worker source serialization (`render.rs:412–420`, `bundle/workers.rs`) snapshots legacy factories and rewrites entry to CJS. Native mixed routing needs an originating bundle snapshot and child-context registration after worker globals install. Until then, Worker-bearing mixed graphs remain legacy. Saved A/B/nested-affinity tests are mandatory.
- **Unrun controls:** native cycle function/var/TDZ read through origin without eager require; opaque getter changes visible through named/default/star/namespace/dynamic import with explicit-over-star/ambiguous/diamond cases; static side-effect order and one CJS evaluation; facade ownKeys/descriptors/integrity; reentrant edge publication. Separately CJS-first sync require, TLA, failed cache rollback, and A/B/nested Workers guard future enablement. None has been run.

The next implementation should start with the private read precursor only if its source-backed namespace timing is verified in the pinned QuickJS API. The mixed native gate stays off until the opaque shell and visitor/facade source-order path are coherent. The historical mixed-ESM finding remains open through all precursors.
