## One ABI rule, two owner classes

Synchronous function and native closure parameters BORROWED; body need not retain merely to read, compare, await under existing owning caller contract, or pass into synchronous borrowed callee. Native Promise-returning functions/closures return one OWNED EXTERNAL handle token; caller adopts it once. Var/field/index/caught-descriptor projection returns BORROWED unless intrinsic explicitly transfers. new/async factory and successful native API owned result returns OWNED. Promise.resolve existing handle/adoption routes must attest actual returnownership, not infer from type. Every return converts its expression to one externally owned handle: transfer an owned local/temporary token or acquire external from borrowed expression; unwind other owned tokens on all normal/error exits. Aliasing same pointer still represents distinct token when independently owned.

Stack lexical owners and external API consumers use external count/root. Arena-owned cells, object fields, closure environments and async frames use INTERNAL GC edges; giving each external root would create Promise->frame/cell->Promise cycles. Runtime already distinguishes internal native_exception_references from total and external_root. Generalize existing internal-retain bookkeeping to owner-slot Promise edges rather than treating all arena aliases as descriptor-only reasons. No universal value registry: reuse cycle-aware internal Promise owner map and existing REFERENCES graph.
