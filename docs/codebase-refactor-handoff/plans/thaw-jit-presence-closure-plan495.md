Globals CALL_PRESENT/CALL_ABSENCE describe the latest helper side effect, not the selected return value. Return an internal callback record {word, presence} from call_jit_callback; representation remains compiler proof, never pointer registry membership. A Dynamic box containing undefined/null is a present valid pointer with an intrinsic tag; distinguish it from a raw optional word whose presence is undefined/null. Do not turn valid Dynamic undefined into a missing pointer.
